Kroblob ist ein Zwerg, der in der Gegend von [[Wald im Blumental]] spurlos verschwunden ist.

| | |
|---|---|
| **Volk** | Zwerg |
| **Status** | verschwunden |
| **Erstmals erwähnt** | Kapitel 2 |

## Was die Gruppe weiß

### Kapitel 2 – Die Schatten
[[Kretzak]] berichtet, dass Kroblob seit einer Woche verschwunden ist und niemand eine Spur von ihm gefunden hat.

Später entdeckt [[Hildrissa]] im Hain eine Brosche, die aus einem frisch aufgewühlten Grab ragt. Zwergische Handwerkskunst, unverwechselbar. [[Diana Eichenblatt|Diana]] behauptet, dort lägen ihre Ahnen, doch niemand glaubt ihr.
